# Brief de discovery

## Preguntas abiertas

1. ¿El primer usuario será una sola persona o varios usuarios con cuentas independientes?
2. ¿Las ofertas se cargarán manualmente mediante texto/URL/archivo o necesitamos una integración desde el inicio?
3. ¿Qué materiales debe generar el MVP: CV adaptado, carta, respuestas de formulario o los tres?
4. ¿Debe almacenar documentos completos en la nube o trabajar con sesiones y exportación temporal?
5. ¿Qué duración y tecnologías están disponibles para la primera demo?

## Supuestos temporales

- El usuario revisa y aprueba cada resultado antes de usarlo.
- El agente no inventa información faltante; pregunta o marca la incertidumbre.
- El MVP puede comenzar con carga manual para reducir riesgos legales, técnicos y de scraping.
- Los datos de una postulación pertenecen al usuario y deben poder eliminarse/exportarse.
